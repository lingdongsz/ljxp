# LJXP Codex Plugin Marketplace

This repository is a Codex plugin marketplace for the `ljxp` plugin.

## Structure

```text
.agents/plugins/marketplace.json
plugins/ljxp/.codex-plugin/plugin.json
plugins/ljxp/skills/ljxp/SKILL.md
plugins/ljxp/skills/ljxp/scripts/
plugins/ljxp/skills/ljxp/references/
```

Add this repository as a Codex plugin marketplace, then install the `ljxp` plugin from it.
